# Employee privacy and usage guide

TeamActivity is designed to be visible. The employee app has a persistent tray icon and shows the current declared work/break state and policy summary.

## Data represented in v0.1

- Work/break/lock/sign-in state.
- Time of the most recent keyboard and mouse input.
- Aggregate keyboard-event count, mouse-event count and movement distance per bucket.
- Device heartbeat, app version, health and pending-upload count.

The data model has no place for which key or mouse button was used. TeamActivity does not collect typed text, clipboard contents, microphone audio, secure-desktop content, messages, or automatic productivity/quality scores.

Screenshot capture and remote support are disabled in v0.1. Future screenshot use requires a notice, working-hours and lock gates, sensitive-app exclusions, personal screenshot history, retention visibility, and report/removal workflow. Future remote support requires a verified manager identity, reason, separate permissions, always-on-top banner and immediate disconnect.

Use the Start work, Start break, End break and End work controls to declare your current state. Contact your administrator to correct records, review retention, obtain an export, or uninstall the application under company policy.
