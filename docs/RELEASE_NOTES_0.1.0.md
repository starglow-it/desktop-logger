# TeamActivity 0.1.0 — security foundation preview

Initial release from an empty repository.

Included: .NET 10 solution, visible employee tray UI, manager dashboard, local manager server, agent heartbeat service, secure enrollment foundation, aggregate activity contracts, SQLite schema, AES-GCM storage primitive, tamper-evident audit chain, consent state machine, deterministic tests and documentation.

Screenshot capture/upload and remote-support media/control are disabled. The server is loopback-only. The release ZIP is a developer preview and is not Authenticode-signed because an organization signing certificate was not available to the build environment. Do not deploy it for employee monitoring or expose it to a LAN.
